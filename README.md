This is a 2D Unity game - EvoDash, developed by me.
In this game you have to get through an obstacle course to get to the finish line using movements like jumping and dashing. 
I connected the game to a cloud database - MongoDB, to create a global leaderboard so people can rank their best times.
You can play the game easily on the web! Go ahead and give it a try, by following the link : https://theodorpopescu.github.io/EvoDash/
